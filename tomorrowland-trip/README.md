# Tomorrow Thailand · 三人小队狂欢周

Leo / Ken / Ocreedy · 12 月芭提雅行程页。面向 **iPhone** 优化，可用 GitHub Pages 分享给朋友（收藏与清单存在每人手机本地）。

## 行程速览

| 日期 | 安排 |
|------|------|
| 12/10 周四 | 无锡 → 广州 → 曼谷（CZ3918 / CZ361） |
| 12/11–13 | Tomorrowland Thailand · Full Madness · Wisdom Valley |
| 12/11–14 | Crystal Palace Hotel Pattaya（含早） |
| 12/14–15 | **需自订**曼谷住宿（酒店已退房，回程 16 日早班） |
| 12/16 周三 | 曼谷 → 广州 → 无锡（CZ362 / CZ3297） |

### 务必补上的两件事

1. **12/10 晚**：22:30 落地 BKK，酒店从 11 日起住——定机场附近一晚，或连夜去芭提雅。  
2. **12/14–15 晚**：订曼谷 2 晚，15 日务必早睡（次日 08:10 起飞）。

## 功能

- 日间浅色 UI，导航在每页标题下方：总览 / 日程 / 出行 / 阵容 / 必看  
- 开幕倒计时、14 天双周日历（关键节点标注）  
- 首页航班卡片 + 中转等待时间 + 机型信息  
- 12/10–16 按日时间线；日程页同样展示双周日历  
- 三日七舞台阵容；DJ 头像懒加载（Commons / Wikipedia）  
- 三人英文全名切换，各自 ★ 必看并可同步链接合并  
- 行前 checklist（本机记住勾选）

## 本地预览

用任意静态服务器打开即可，例如：

```bash
cd tomorrowland-trip
npx --yes serve .
```

或直接双击 `index.html`（部分浏览器对本地 `file://` 限制较少，一般可用）。

## 发布到 GitHub Pages

1. 新建仓库，把本目录内容推上去  
2. Settings → Pages → Source 选 `main` / `/ (root)`  
3. 把 Pages 地址发给朋友；每人打开后先点右上角切换「我是谁」

可选：把仓库 Pages 地址写进群公告。

## 隐私说明

公开页**未写入**邮箱等联系方式。航班乘客名仅用于你们内部核对；若仓库设为 Public，可按需再脱敏。
